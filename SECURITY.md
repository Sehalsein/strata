# Security

If you find a security problem in Strata, please report it privately: use
**Report a vulnerability** on the repository's
[Security tab](https://github.com/Sehalsein/strata/security/advisories/new) rather than
opening an issue.

Include what you found, how to reproduce it, and which part it affects (server,
dashboard or Apple apps). Strata is a personal project, so there's no bounty and no
guaranteed response time, but reports are read and fixed where they apply.

Strata is self-hosted: each server is run by its owner, and there's no central service
to report against.
