# Privacy policy

*Strata for iPhone, iPad and Apple TV. Last updated October 21, 2026.*

Strata is an app for a media server you run yourself. The developer doesn't run any
servers for it, and doesn't collect, receive or store any data about you or how you use
the app. There's no analytics, advertising or tracking.

## What the app sends, and where

- **Your Strata server.** The app talks to the server you connect it to: your sign-in,
  profile choice, what you browse and play, and your watch progress. That server is yours
  (or belongs to whoever invited you), and what it keeps is up to the person running it.
- **TMDB** ([themoviedb.org](https://www.themoviedb.org/privacy-policy)). Posters and
  artwork load from TMDB's image servers. Those requests include your IP address, as any
  web request does.
- **YouTube** ([youtube.com](https://policies.google.com/privacy)). Only if you open a
  trailer, which plays from YouTube.

## On your device

The app keeps the servers you've added, and a sign-in token for each in the system
Keychain. It caches artwork and catalog pages to load faster. Deleting the app removes
all of it.

## Children

A server's owner can set up Kids profiles with content limits. The app doesn't collect
data from children or anyone else.
